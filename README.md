# 📊 График командировок

Интерактивное веб-приложение для визуализации командировок специалистов.

## 🚀 Возможности

- **Гант-диаграмма** — наглядное отображение командировок во времени
- **Фильтрация** — просмотр командировок по конкретному специалисту
- **Добавление/редактирование** — форма прямо в приложении
- **Экспорт/импорт** — сохранение и восстановление данных в JSON
- **Адаптивный дизайн** — работает на телефоне и компьютере
- **Тёмная тема** — современный UI с градиентами

## 🛠 Технологии

- **Next.js 14** (React) — фреймворк
- **Tailwind CSS** — стили
- **TypeScript** — типизация
- **localStorage** — хранение данных
- **Vercel** — хостинг

## 📦 Локальный запуск

```bash
npm install
npm run dev
```

Открой http://localhost:3000

## 🌐 Деплой на Vercel

1. Зайди на [vercel.com/new](https://vercel.com/new)
2. Войди через GitHub
3. Выбери репозиторий `trip-schedule-app`
4. Нажми Deploy

Vercel автоматически определит Next.js и соберёт проект.

## 📝 Как работать

### Добавить командировку
- Нажми кнопку "+ Добавить" в правом верхнем углу
- Заполни форму (можно добавить нового специалиста прямо там)

### Посмотреть детали
- Кликни на цветную полоску командировки
- Откроется карточка с деталями, кнопки "Изменить" и "Удалить"

### Фильтровать
- Нажми на чип специалиста над графиком
- Повторный клик снимает фильтр

### Сохранить данные
- Нажми иконку ↓ — скачается JSON-файл
- Нажми иконку ↑ — загрузи ранее сохранённый JSON
- Нажми ↻ — вернёт демо-данные (с подтверждением)

## 📂 Структура

```
├── app/
│   ├── layout.tsx      # Корневой layout
│   ├── page.tsx        # Главная страница (управление состоянием)
│   └── globals.css     # Стили
├── components/
│   ├── Header.tsx      # Шапка с кнопками
│   ├── FilterChips.tsx # Фильтры
│   ├── Timeline.tsx    # Гант-диаграмма
│   ├── AddTripModal.tsx    # Форма добавления
│   └── TripDetailsModal.tsx # Детали
├── lib/
│   ├── types.ts        # Типы
│   ├── data.ts         # Сид-данные и утилиты дат
│   └── storage.ts      # localStorage
└── _legacy_streamlit/  # Старая версия (Streamlit)
```

## ⚠️ Важно

Данные хранятся в `localStorage` браузера. Если очистить кеш — данные пропадут. Используй **Экспорт** для резервной копии.
