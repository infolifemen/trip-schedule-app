# План исправления: Sticky Header и Производительность

**Дата:** 2026-10-19  
**Проект:** График командировок (trip-schedule)  
**Статус:** В работе

## Проблемы

### 1. Полоса с датами не прилипает к верху окна
**Симптом:** При вертикальном скролле полоса с датами скрывается (уезжает вверх)  
**Причина:** Скролл-контейнер не получает корректную высоту (`height: 100%` не работает в flex-контексте)  
**Решение:** Использовать `position: absolute` для скролл-контейнера, чтобы гарантировать явную высоту

### 2. Полоса с датами наезжает на левую колонку при горизонтальном скролле
**Симптом:** При скролле вправо/влево даты перекрывают блок "ОБЪЕКТ — ВИД РАБОТ"  
**Причина:** Возможно проблема с z-index или stacking context  
**Решение:** Убедиться, что левая колонка (z-index: 35) выше даты (z-index: 25), добавить непрозрачный фон

### 3. Медленная загрузка страницы
**Симптом:** Страница загружается долго, показывается "Загрузка..."  
**Причина:** Приложение ждет полной загрузки данных из Supabase перед рендером  
**Решение:** 
- Рендерить UI немедленно с seed-данными
- Загружать данные асинхронно в фоне
- Показывать skeleton loader только если данных нет вообще

## План реализации

### Шаг 1: Исправить высоту скролл-контейнера
```tsx
// БЫЛО:
<div style={{ width: "100%", height: "100%", overflow: "auto" }}>

// СТАНЕТ:
<div style={{ position: "absolute", top: 0, bottom: 0, left: 0, right: 0, overflow: "auto" }}>
```

### Шаг 2: Усилить z-index для левой колонки
- Убедиться, что левая колонка имеет `background: "rgba(255,255,255,0.98)"` (почти непрозрачный)
- Проверить, что `z-index: 35` выше `z-index: 25` даты
- Добавить `box-shadow` для визуального разделения

### Шаг 3: Оптимизировать загрузку
```tsx
// БЫЛО:
useEffect(() => {
  loadData().then((result) => {
    setData(result);
    setLoaded(true);
  });
}, []);

if (loading) return <div>Загрузка...</div>;

// СТАНЕТ:
const [data, setData] = useState<AppData>(SEED_DATA); // Сразу показываем seed
const [loaded, setLoaded] = useState(false);

useEffect(() => {
  loadData().then((result) => {
    setData(result); // Обновляем данными из Supabase
    setLoaded(true);
  });
}, []);

// Рендерим сразу, без loading state
```

### Шаг 4: Тестирование
- Проверить вертикальный скролл: дата должна прилипать к верху
- Проверить горизонтальный скролл: дата должна уходить под левую колонку
- Проверить скорость загрузки: UI должен появиться мгновенно

## Ожидаемый результат

1. ✅ Полоса с датами всегда видна при вертикальном скролле (прилипает к верху)
2. ✅ При горизонтальном скролле дата уходит под левую колонку "ОБЪЕКТ — ВИД РАБОТ"
