# Процесс деплоя проекта "График командировок"

## ВАЖНО: После ЛЮБЫХ изменений в коде

### Обязательный процесс:

1. **Изменение кода** → сохранить файл
2. **Git commit + push** (любым способом):
   - Автоматически через git hooks (если активированы)
   - Вручную: `git add . && git commit -m "..." && git push origin main`
   - Через скрипт: `auto-deploy.bat`

3. **Подождать 1-2 минуты** для деплоя через GitHub Actions

4. **Обновить браузер** (Ctrl+F5) и проверить изменения

## Способы коммита и пуша

### Способ 1: Автоматический (через git hooks)

Если hooks установлены и активированы:
```bash
git commit -m "Описание изменений"
# pre-commit: автоматически pull
# commit: создаётся
# post-commit: автоматически push
```

### Способ 2: Вручную (надёжный)
```bash
git add .
git commit -m "Описание изменений"
git push origin main
```

### Способ 3: Через скрипт (Windows)
```cmd
auto-deploy.bat
```

### Способ 4: Через агент
Агент **всегда** коммитит и пушит изменения автоматически после правки кода.

## Проверка работы

### Проверить статус git:
```bash
git status
git log --oneline -5
```

### Проверить push:
```bash
git log origin/main --oneline -5
```

## Если изменения не видны в браузере

1. **Проверьте git status** — есть ли незакоммиченные изменения?
2. **Проверьте последний коммит** — содержит ли он ваши правки?
   ```bash
   git show HEAD
   ```
3. **Проверьте push** — отправлен ли коммит на GitHub?
   ```bash
   git log origin/main --oneline -1
   ```
4. **Проверьте GitHub Actions** — успешно ли завершился деплой?
   - URL: https://github.com/infolifemen/trip-schedule-app/actions
5. **Очистите кэш браузера** (Ctrl+F5 или Cmd+Shift+R)
6. **Подождите 1-2 минуты** — GitHub Pages может деплоиться медленно

## Git Hooks

### Установка hooks:
```cmd
install-hooks.bat
```

### Что делают hooks:
- **pre-commit**: автоматически pull перед коммитом (синхронизация)
- **post-commit**: автоматически push после коммита (деплой)

### Проверка hooks:
```bash
ls -la .git/hooks/
```

## Правила для агента

**ПРИ ЛЮБЫХ ИЗМЕНЕНИЯХ В КОДЕ:**

1. ✅ Всегда коммитить и пушить изменения
2. ✅ Проверять что push успешен
3. ✅ Сообщать пользователю о деплое
4. ✅ Ждать 1-2 минуты перед проверкой в браузере
5. ✅ НЕ оставлять локальные изменения "в памяти"

**ЗАПРЕЩЕНО:**
- ❌ Изменять код без коммита
- ❌ Забывать про push
- ❌ Оставлять незакоммиченные изменения
- ❌ Возвращаться к старым багам (регрессии)

## Архитектура деплоя

```
Локальные изменения
       ↓
  git add + commit
       ↓
  git push origin main
       ↓
GitHub Actions (deploy.yml)
       ↓
Build Next.js → static export
       ↓
GitHub Pages (gh-pages branch)
       ↓
Доступно на: https://infolifemen.github.io/trip-schedule-app/
```

## Контакты

Если что-то не работает:
1. Проверьте логи GitHub Actions
2. Проверьте консоль браузера (F12)
3. Проверьте статус git репозитория
